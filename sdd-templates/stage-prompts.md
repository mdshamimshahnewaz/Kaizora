# Optional stage prompts

These are examples, not mandatory approval phrases. Natural-language user direction
is valid. Record actual authority; never manufacture approval.

- “Draft the feature spec and list open questions. Do not implement yet.”
- “I approve this spec; prepare the design and task breakdown.”
- “Implement this feature within the agreed scope and verify it.”
- “Revise the requirement as follows; update the affected design, tasks and tests.”
- “I accept the recorded verification with these specific limitations: …”

See docs/sdd-workflow.md for staged and end-to-end authorisation.
